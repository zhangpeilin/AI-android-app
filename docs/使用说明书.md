# ComicReader 漫画阅读器 - 使用说明书

> 版本：v1.1

---

## 一、快速开始

### 1.1 导入本地漫画

1. 打开应用，进入**漫画列表**首页
2. 点击右上角的 📂 **文件夹图标**
3. 选择存放漫画 ZIP 文件的文件夹
4. 应用自动扫描并显示所有漫画

> **支持的格式**：ZIP 压缩包，包内为图片文件（JPG/PNG/WebP）

### 1.2 从 WebDAV 服务器下载漫画

1. 点击首页右上角的 ☁️ **云朵图标**，进入 WebDAV 服务器管理
2. 点击右下角 **+** 按钮添加服务器
3. 填写服务器信息：
   - **名称**：如"我的 NAS"
   - **服务器地址**：如 `https://192.168.1.100:5005/dav/`
   - **用户名**和**密码**
4. 点击 **添加** 保存
5. 点击服务器名称进入文件浏览
6. 找到漫画 ZIP 文件，点击下载并自动打开

---

## 二、首页（漫画列表）

### 2.1 视图切换

- 点击右上角 **列表/网格图标** 切换显示方式：
  - **网格视图**：3 列卡片，显示封面和标题
  - **列表视图**：横向卡片，显示封面、标题和文件大小

### 2.2 搜索漫画

- 在顶部搜索栏输入漫画名称，实时过滤显示结果

### 2.3 打开漫画

- 点击任意漫画卡片进入章节列表

---

## 三、章节列表

- 显示漫画的所有章节，每话标注页数
- 点击任意章节进入阅读
- **单话漫画**：自动跳过章节列表，直接进入阅读

### 导航按钮

| 按钮 | 功能 |
|------|------|
| ← 返回箭头 | 返回上一页 |
| 🏠 首页 | 直接返回漫画列表首页 |

---

## 四、阅读器

### 4.1 阅读模式

应用支持两种阅读模式，默认**垂直模式**：

#### 垂直模式（长条漫画）
- 上下滑动浏览，所有页面垂直拼接
- 适合条漫、Webtoon 等长条格式漫画

#### 水平模式（翻页漫画）
- 左右滑动翻页，每次显示一页
- 顶部显示"当前页 / 总页数"

**切换模式**：点击顶部栏右侧的 **模式切换图标**

### 4.2 阅读进度记忆

- 应用自动记录您的阅读位置（漫画、章节、页码）
- 再次打开同一漫画时，弹出对话框：
  - 点击 **"继续"**：跳转到上次阅读位置
  - 点击 **"从头开始"**：从第 1 页开始

### 4.3 图片缩放（水平模式）

- **双击** 图片：放大 2 倍
- **再次双击**：恢复原始大小
- **双指捏合**：自由缩放（1x ~ 5x）
- 放大后可**拖动**查看细节

### 4.4 顶部栏显示/隐藏

- 点击**屏幕中央区域**可隐藏/显示顶部栏
- 隐藏顶部栏可获得全屏阅读体验

### 4.5 右侧进度条

- **滚动时**自动显示（半透明）
- **停止滚动** 3 秒后自动隐藏
- **点击或拖动**进度条可快速跳转到任意页
- 拖动时显示"当前页 / 总页数"浮层

### 4.6 导航按钮

| 按钮 | 功能 |
|------|------|
| ← 返回箭头 | 返回章节列表 |
| 🏠 首页 | 直接返回漫画列表首页 |
| 模式切换图标 | 在水平/垂直模式间切换 |

## 五、WebDAV 服务器管理

### 5.1 添加服务器

1. 进入 WebDAV 管理页面
2. 点击右下角 **+** 按钮
3. 填写信息并点击"添加"

### 5.2 管理服务器

每个服务器提供三个操作：
- ✏️ **编辑**：修改服务器信息
- ✓ **测试连接**：验证服务器是否可达
- 🗑️ **删除**：移除服务器配置

---

## 六、WebDAV 文件浏览

### 6.1 浏览目录

- 点击**文件夹**进入子目录
- 点击**返回箭头**或**系统返回键**回到上级目录
- 顶部显示当前路径

### 6.2 下载并阅读漫画

1. 找到漫画 ZIP 文件（以 `.zip` 结尾）
2. 点击文件开始下载
3. 顶部进度条显示下载进度
4. 下载完成后自动进入漫画章节列表

### 6.3 目录记忆

- 应用记住您上次浏览到的目录位置
- 下次打开同一服务器时，直接从上次目录开始，无需重新导航

### 6.4 导航按钮

| 按钮 | 功能 |
|------|------|
| ← 返回箭头 | 返回上级目录（到根目录后退出浏览页） |
| 🏠 首页 | 直接返回漫画列表首页 |

## 七、常见问题

### Q：支持哪些漫画格式？
A：目前支持 ZIP 格式的压缩包，包内为图片文件（JPG、PNG、WebP）。

### Q：漫画文件有大小限制吗？
A：没有硬性限制，但过大的 ZIP 文件可能导致加载较慢。

### Q：阅读进度保存在哪里？
A：保存在应用本地存储中，卸载应用会丢失阅读进度。

### Q：WebDAV 下载的漫画存在哪里？
A：下载后保存在应用私有目录，与本地扫描的漫画统一管理。

### Q：如何删除已下载的漫画？
A：目前暂不支持应用内删除，需要通过文件管理器手动删除。

### Q：水平模式下翻页不灵敏？
A：确保在未放大状态下滑动，放大后手势用于拖动图片而非翻页。
