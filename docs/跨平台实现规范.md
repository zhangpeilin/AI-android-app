# ComicReader 跨平台实现规范

> 本文档基于 Android 原生实现（Kotlin + Jetpack Compose）逆向整理，供其他平台（iOS/Web/Desktop/Flutter 等）开发人员和 AI Agent 参考。

---

## 1. 系统架构

### 1.1 整体分层

```
┌─────────────────────────────────────────┐
│              UI 层 (Screens)             │
│  ComicList / ChapterList / Reader /      │
│  ServerSettings / WebDavBrowse           │
├─────────────────────────────────────────┤
│           状态管理层 (ViewModel)          │
│  ComicListVM / ComicReaderVM /           │
│  ServerSettingsVM / WebDavBrowseVM       │
├─────────────────────────────────────────┤
│            数据仓库层 (Repository)        │
│  ComicRepository / WebDavServerRepository│
├─────────────────────────────────────────┤
│            基础服务层 (Service)           │
│  WebDavClient (HTTP) / ZipHelper (IO)    │
├─────────────────────────────────────────┤
│             持久化层 (Storage)            │
│  KeyValue Store (JSON序列化)             │
└─────────────────────────────────────────┘
```

### 1.2 导航路由

```
/comic_list                              ← 首页（起点）
/chapter_list?comicId={}&title={}        ← 章节列表
/reader?comicId={}&title={}&chapter={}   ← 阅读器
/server_settings                         ← WebDAV 服务器管理
/webdav_browse?serverId={}               ← WebDAV 文件浏览
```

**导航栈行为**：
- 普通前进：`push` 新页面
- 返回：`pop` 当前页面
- 首页按钮：`popToRoot`（回到 `/comic_list`，清空栈）
- 单话漫画自动跳转：`push` 阅读器 + `remove` 章节列表页（防止返回时再次显示）

## 2. 数据模型

### 2.1 Comic（漫画）

```
Comic {
  id: String          // MD5(filePath)，唯一标识
  title: String       // 漫画标题 = ZIP文件名去掉 .zip 后缀
  filePath: String    // ZIP 文件的本地绝对路径
  fileSize: Integer   // 文件大小（字节）
}
```

**ID 生成算法**：
```
function generateId(filePath: String) -> String:
  bytes = MD5(filePath.encode("UTF-8"))
  return bytes.map(b => format("%02x", b)).join("")
```

### 2.2 Chapter（章节）

```
Chapter {
  number: String          // 章节号
  images: List<String>    // 该章节内所有图片的路径列表（已排序）
}
```

### 2.3 WebDavServerConfig（WebDAV 服务器配置）

```
WebDavServerConfig {
  id: String          // UUID
  name: String        // 显示名称，如"我的NAS"
  url: String         // 服务器地址，必须以 http:// 或 https:// 开头，以 / 结尾
  username: String    // 用户名
  password: String    // 密码
  lastPath: String    // 上次浏览的目录路径，默认 "/"
}
```

### 2.4 WebDavEntry（WebDAV 目录条目）

```
WebDavEntry {
  name: String          // 文件/文件夹显示名
  path: String          // 完整路径（WebDAV href，相对于服务器根目录）
  isDirectory: Boolean  // 是否为目录
  size: Integer         // 文件大小（字节），目录为 0
}
```

### 2.5 ReadingProgress（阅读进度，持久化存储）

```
ReadingProgress {
  chapter: String       // 章节号
  pageIndex: Integer    // 页码（从 0 开始）
  timestamp: Integer    // 保存时间戳（毫秒）
}
```

## 3. 功能模块详细规格

### 3.1 漫画列表页（ComicListScreen）

#### 状态

| 状态 | 类型 | 说明 |
|------|------|------|
| comics | List\<Comic\> | 当前显示的漫画列表 |
| isLoading | Boolean | 是否正在扫描文件夹 |
| searchQuery | String | 搜索关键词 |
| selectedFolderName | String? | 已选文件夹的显示名 |
| isGridView | Boolean | true=网格视图，false=列表视图，默认 true |

#### 行为

**初始化**：
1. 页面加载时调用 `loadComics()` 刷新列表
2. 从持久化存储加载已下载的 WebDAV 漫画

**扫描本地文件夹**：
1. 调用系统文件夹选择器（平台相关）
2. 递归扫描所选文件夹中的所有 `.zip` 文件
3. 将 ZIP 文件复制到应用缓存目录（`comic_zips/`）
4. 对每个 ZIP：`id = MD5(filePath)`, `title = 文件名去掉.zip`
5. 存入内存缓存 `Map<id, Comic>`

**搜索过滤**：
- 实时过滤，`query` 变化时重新计算
- 支持**简繁体混合匹配**（见 §6.2）
- 空查询时返回全部漫画

**漫画卡片显示**：
- **封面提取**：从 ZIP 第一张图片生成，缩放到 300×400 JPEG
- **网格视图**：3列，封面+标题（最多2行，溢出省略）
- **列表视图**：横向卡片，封面(75px宽)+标题+文件大小
- 文件大小格式化：`B / KB / MB / GB`

**进入漫画**：
- 点击卡片 → 导航到 `/chapter_list?comicId={}&title={}`

### 3.3 阅读器页（ReaderScreen）

#### 状态

| 状态 | 类型 | Key | 说明 |
|------|------|-----|------|
| images | List\<String\> | - | 当前章节的图片路径列表 |
| isLoading | Boolean | - | 是否正在加载 |
| readingMode | Enum | comicId | HORIZONTAL / VERTICAL，默认 VERTICAL |
| currentPageIndex | Int | comicId+chapter | 当前页码（从 0 开始） |
| showTopBar | Boolean | - | 顶部栏是否显示，默认 true |
| isImagesReady | Bool | comicId+chapter | 图片是否加载完成 |
| isProgressRestored | Bool | comicId+chapter | 进度是否已恢复（防覆盖保护） |
| savedProgress | (chapter, page)? | comicId | 从存储读取的上次进度 |
| showProgressDialog | Bool | comicId | 是否显示继续阅读对话框 |
| handledSessions | Set\<String\> | ViewModel全局 | 已处理过对话框的 "comicId#chapter" 集合 |

> **Key 列**表示该状态在重置/隔离时使用的 key。相同 comicId 的状态共享，不同 comicId 的状态独立。

#### 阅读进度状态机

```
┌─ 打开漫画 ──────────────────────────────────────────┐
│                                                      │
│  LaunchedEffect(comicId, chapter):                   │
│    isImagesReady = false                             │
│    isProgressRestored = false                        │
│    loadImages(comicId, chapter)                      │
│                                                      │
│  LaunchedEffect(images 加载完成):                     │
│    isImagesReady = true                              │
│                                                      │
│    IF NOT handledSessions.contains(key)              │
│       AND savedProgress == null:                     │
│      ┌─ 查询持久化进度 ─┐                            │
│      │ 有记录 → 弹对话框 │                            │
│      │ 无记录 → 标记恢复 │                            │
│      └──────────────────┘                            │
│                                                      │
│    ELSE IF handledSessions.contains(key):            │
│      // composable 重建场景                           │
│      restoredPage = getLastSavedPageIndex(comicId)   │
│      currentPageIndex = clamp(restoredPage, 0, max)  │
│                                                      │
│  对话框处理（所有路径）:                               │
│    showProgressDialog = false                        │
│    savedProgress = null          ← 关键！清除残留     │
│    handledSessions.add(key)                          │
│    isProgressRestored = true                         │
│                                                      │
│  LaunchedEffect(currentPageIndex):                   │
│    IF isImagesReady AND isProgressRestored:          │
│      saveReadingProgress(comicId, chapter, page)     │
│                                                      │
│  页面销毁时:                                          │
│    handledSessions.remove(key)   ← 清除，下次重弹     │
└──────────────────────────────────────────────────────┘
```

### 3.5 WebDAV 文件浏览页（WebDavBrowseScreen）

#### 状态

| 状态 | 类型 | 说明 |
|------|------|------|
| entries | List\<WebDavEntry\> | 当前目录的文件列表 |
| currentPath | String | 当前路径，默认 "/" |
| isLoading | Boolean | 是否正在加载 |
| downloadProgress | Float? | 下载进度 0.0~1.0，null 表示未下载 |
| error | String? | 错误信息 |

#### 行为

**初始化**：
1. 根据 `serverId` 从存储加载服务器配置
2. 从 `config.lastPath` 开始浏览（不是从 "/" 开始！）

**目录浏览**：
- 点击文件夹 → `loadDirectory(entry.path)`
- 每次进入目录 → 保存 `lastPath` 到服务器配置

**返回行为**：
```
function goBack() -> Boolean:
  IF currentPath == "/": return false  // 已到根目录
  parentPath = currentPath.trimEnd('/').substringBeforeLast('/', "/")
  loadDirectory(parentPath)
  return true
```

- 系统返回键：优先 `goBack()`，到根目录后才真正退出页面
- 顶部返回箭头：同 `goBack()` 逻辑

**下载漫画**：
1. 用户点击 `.zip` 文件
2. 显示下载进度条（固定在顶部栏下方，不随内容滚动）
3. 后台下载到缓存目录 `comic_zips/webdav_{hash}_{fileName}`
4. 下载完成后注册到漫画库并持久化
5. 自动导航到 `/chapter_list`
6. 防重复下载：同一文件不重复下载

**错误处理**：
- 网络失败 → 显示错误信息 + "重试"按钮
- 重试 → `loadDirectory(currentPath)`

## 5. ZIP 文件处理

### 5.1 章节解析逻辑

```
function getChapters(zipFile) -> List<Chapter>:
  allEntries = zipFile.entries()
  imageEntries = allEntries.filter(e => !e.isDirectory AND isImage(e.name))
  
  hasSubDirs = imageEntries.any(e => e.name.contains("/"))
  
  IF NOT hasSubDirs:
    // 扁平结构：所有图片归为 1 个章节
    sorted = imageEntries.map(e => e.name).sort(numericSort)
    return [Chapter(number="1", images=sorted)]
  
  ELSE:
    // 子目录结构：每个第一级子目录是一个章节
    chapterMap = Map<String, List<String>>()
    for entry in imageEntries:
      parts = entry.name.split("/")
      if parts.size >= 2:
        chapterName = parts[0]
        fileName = parts.last()
        chapterMap[chapterName].append(fileName)
    
    // 每章内图片按数字排序，章节按章节号排序
    chapters = chapterMap.map((name, images) =>
      Chapter(number=name, images=images.sort(numericSort))
    ).sortBy(chapter.number.toInt or 0)
    return chapters
```

### 5.2 支持的图片格式

```
.jpg, .jpeg, .png, .gif, .webp, .bmp
```

### 5.3 图片文件名排序算法

**自然数字排序**（非字典序）：
```
function numericSort(a, b):
  numA = extractNumber(a)  // 提取文件名中的数字部分
  numB = extractNumber(b)
  if numA AND numB: return numA.compareTo(numB)
  else: return a.compareTo(b)

function extractNumber(fileName):
  name = fileName.substringBeforeLast('.')
  return name.filter(isDigit).toIntOrNull()
```

示例：`001.jpg, 002.jpg, ..., 010.jpg` → 按 1,2,...,10 排序（非 1,10,2,...）

### 5.4 封面提取

```
function extractCover(zipFile) -> bytes:
  chapters = getChapters(zipFile)
  firstImage = chapters[0].images[0]
  rawBytes = readFromZip(zipFile, firstImage)
  bitmap = decodeImage(rawBytes)
  scaled = resize(bitmap, 300, 400)  // 缩放到 300x400
  return encodeJPEG(scaled, quality=80)
```

### 5.5 读取 ZIP 内图片

```
function getImageBytes(zipFile, imagePath, chapter=null) -> bytes:
  entry = zipFile.getEntry(imagePath)
  if entry == null AND chapter != null:
    entry = zipFile.getEntry("{chapter}/{imagePath}")  // 子目录结构时补前缀
  if entry == null: return null
  return zipFile.getInputStream(entry).readAllBytes()
```

## 6. WebDAV 协议实现

### 6.1 PROPFIND 列目录

**请求**：
```
PROPFIND {baseUrl}{path} HTTP/1.1
Depth: 1
Content-Type: application/xml; charset=utf-8
Authorization: Basic {base64(username:password)}

<?xml version="1.0" encoding="utf-8"?>
<D:propfind xmlns:D="DAV:">
  <D:prop>
    <D:displayname/>
    <D:resourcetype/>
    <D:getcontentlength/>
  </D:prop>
</D:propfind>
```

**响应解析**：
- XML `<multistatus>` 包含多个 `<response>`
- 每个 `<response>` 提取：
  - `<href>` → `WebDavEntry.path`
  - `<displayname>` → `WebDavEntry.name`（若为空，从 href 提取文件名并 URL 解码）
  - `<collection>` 是否存在 → `WebDavEntry.isDirectory`
  - `<getcontentlength>` → `WebDavEntry.size`
- **排除**：请求路径本身（目录自身）不出现在结果中
- **排序**：目录在前，文件在后，各自按名称字母序

**URL 构建逻辑**：
```
function buildFullUrl(baseUrl, path):
  schemeHost = extractSchemeAndHost(baseUrl)  // http://192.168.3.39
  basePath = extractBasePath(baseUrl)         // /webdav
  
  // href 可能已包含 basePath
  if basePath AND path.startsWith(basePath):
    return schemeHost + path
  else:
    return baseUrl.trimEnd('/') + '/' + path
```

### 6.2 文件下载（GET）

```
GET {fullUrl} HTTP/1.1
Authorization: Basic {credentials}

// 响应：流式读取，8192 字节缓冲区
// 进度回调：onProgress(downloadedBytes, totalBytes)
// totalBytes 从 Content-Length 头获取
// 下载失败时删除不完整的本地文件
```

### 6.3 HTTP 客户端配置

| 参数 | 值 |
|------|-----|
| 连接超时 | 30 秒 |
| 读取超时 | 60 秒 |
| 写入超时 | 30 秒 |
| 认证方式 | Basic Auth（Authorization 头） |
| 认证重试 | 最多 1 次（已有 Authorization 头时不重试） |

### 6.4 测试连接

```

    return false

## 7. 搜索功能

### 7.1 简繁体混合匹配

```
function searchComics(query, allComics) -> List<Comic>:
  if query.isBlank(): return allComics
  keyword = query.lowercase()
  return allComics.filter(comic =>
    matchText(comic.title, keyword)
  )

function matchText(text, keyword) -> Boolean:
  textLower = text.lowercase()
  if textLower.contains(keyword): return true
  
  // 简繁互转后再次匹配
  textTrad = toTraditional(textLower)
  textSimp = toSimplified(textLower)
  kwTrad = toTraditional(keyword)
  kwSimp = toSimplified(keyword)
  
  return textTrad.contains(kwTrad)
      OR textTrad.contains(kwSimp)
      OR textSimp.contains(kwTrad)
      OR textSimp.contains(kwSimp)
```

    ELSE:
      copy(original, cacheFile)  // 复制到缓存
```

## 9. 关键交互细节

### 9.1 点击区域划分（阅读器）

```
屏幕宽度 W, 屏幕高度 H
中心点 (W/2, H/2)
点击位置 (x, y)
dx = x - W/2, dy = y - H/2

IF |dx| < W*0.3 AND |dy| < H*0.3:
  → 切换顶部栏显示/隐藏（中央 60% 区域）
ELSE:
  → 交给底层翻页/滚动手势处理
```

### 9.2 图片缩放状态机

```
初始状态: scale=1.0, offsetX=0, offsetY=0

双击:
  IF scale > 1.5: → scale=1.0, offset=0（缩小）
  ELSE:           → scale=2.0（放大）

双指缩放:
  newScale = clamp(scale * zoomFactor, 1.0, 5.0)
  IF newScale > 1.0:
    offsetX += pan.x
    offsetY += pan.y
  ELSE:
    offsetX = 0, offsetY = 0

手势拦截规则:
  IF scale > 1.01: 拦截所有触摸事件（用于缩放/平移）
  ELSE:            不拦截（让翻页组件处理）
```

### 9.3 进度条拖动逻辑

```
按下:
  isDragging = true
  isFullOpacity = true
  progress = clamp(y / barHeight, 0, 1)
  newPage = (progress * (totalPages - 1)).toInt()
  jumpToPage(newPage)

拖动:
  dragPosition = clamp(y, 0, barHeight)
  progress = dragPosition / barHeight
  newPage = (progress * (totalPages - 1)).toInt()
  IF newPage != lastJumpPage:
    lastJumpPage = newPage
    jumpToPage(newPage)

抬起:
  isDragging = false
  isFullOpacity = false
```

### 9.4 垂直模式滚动速度检测

```
每 50ms 采样:
  currentPosition = firstVisibleItemIndex * 10000 + firstVisibleItemScrollOffset
  currentTime = now()
  timeDelta = currentTime - lastTime
  
  IF timeDelta > 0 AND lastTime > 0:
    velocity = |currentPosition - lastPosition| / timeDelta * 1000
    isFastScrolling = velocity > 2000
    
  lastPosition = currentPosition
  lastTime = currentTime

滚动停止:
  isFastScrolling = false
  lastTime = 0
```

### 10.1 替代方案参考

| Android 组件 | iOS 替代 | Web 替代 | Flutter 替代 |

### 10.2 注意事项

1. **WebDAV PROPFIND**：部分 HTTP 客户端不支持自定义 HTTP Method，需确认
2. **ZIP 中文文件名**：ZIP 内文件名可能是 GBK 编码，需要处理
3. **大文件处理**：ZIP 可能很大，需要流式读取而非全部加载到内存
4. **图片内存管理**：需要限制内存中同时存在的图片数量
5. **状态隔离**：阅读进度等状态必须按 comicId 隔离，切换漫画时不能串数据
6. **URL 编码**：WebDAV href 中的路径可能包含 URL 编码的中文，需正确解码
7. **线程安全**：下载任务、缓存操作需考虑并发安全
