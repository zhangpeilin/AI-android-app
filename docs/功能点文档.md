# ComicReader 漫画阅读器 - 功能点文档

> 版本：v1.1 | 最后更新：2025-07-10

---

## 一、项目概览

| 项目 | 说明 |
|------|------|
| 平台 | Android 8.0+ (SDK 24+) |
| UI 框架 | Jetpack Compose + Material3 |
| 架构 | MVVM |
| 图片加载 | Coil |
| 网络 | OkHttp 4.12 (WebDAV) |
| 文件解析 | Android SAF (ZIP 漫画) |
| 导航 | Navigation Compose |

---

## 二、导航结构

```
comic_list (首页)
  ├── chapter_list/{comicId}/{title} (章节列表)
  │     └── reader/{comicId}/{title}/{chapter} (阅读器)
  ├── server_settings (WebDAV 服务器管理)
  │     └── webdav_browse/{serverId} (WebDAV 文件浏览)
  │           └── chapter_list/{comicId}/{title} → reader/...
```

**起点**：`comic_list`（漫画列表页）

## 三、功能模块

### 3.1 首页 - ComicListScreen

**文件**：`ui/screens/ComicListScreen.kt`  
**ViewModel**：`viewmodel/ComicListViewModel.kt`

| 功能点 | 说明 |
|--------|------|
| SAF 文件夹扫描 | 通过 `OpenDocumentTree` 选择本地文件夹，扫描其中的 ZIP 漫画文件 |
| 漫画列表展示 | 支持**网格视图**（3列，带封面）和**列表视图**（横向卡片，带封面+文件大小） |
| 封面图显示 | 从 ZIP 内第一张图片提取封面，使用 Coil `AsyncImage` 加载 |
| 搜索过滤 | 输入框实时过滤漫画标题，模糊匹配 |
| 每次进入刷新 | `LaunchedEffect(Unit)` 刷新列表，确保从 WebDAV 下载的新漫画立即可见 |
| WebDAV 入口 | 顶部栏云朵图标跳转到服务器管理页 |
| 文件夹提示 | 已选文件夹名称显示在搜索栏下方 |

**关键状态**：
- `comics: StateFlow<List<Comic>>` — 当前漫画列表
- `searchQuery: StateFlow<String>` — 搜索关键词
- `selectedFolderName: StateFlow<String?>` — 已选文件夹名

### 3.2 章节列表 - ChapterListScreen

**文件**：`ui/screens/ChapterListScreen.kt`

| 功能点 | 说明 |
|--------|------|
| 章节列表展示 | 显示每话标题和页数 |
| 单话自动跳转 | 当 `chapters.size == 1` 时，自动跳转到阅读器，跳过章节选择 |
| 自动跳转防重复 | `hasAutoOpened: remember(comicId)` 防止返回后重复触发自动跳转 |

**单话自动跳转注意事项**：

- 必须在返回后不重复触发，否则用户按返回时会被瞬间重定向回阅读器

### 3.3 阅读器 - ReaderScreen

**文件**：`ui/screens/ReaderScreen.kt`  
**ViewModel**：`viewmodel/ComicReaderViewModel.kt`

#### 3.3.1 核心功能

| 功能点 | 说明 |
|--------|------|
| 双模式阅读 | **水平翻页**（HorizontalPager）/ **垂直长条**（LazyColumn） |
| 模式切换 | 顶部栏按钮切换，`readingMode: remember(comicId)` |
| 阅读进度记忆 | 自动保存当前页码（SharedPreferences），下次打开弹出"继续阅读"对话框 |
| 进度对话框 | 显示上次读到第X话第Y页，可选"继续"或"从头开始" |
| 顶栏显示/隐藏 | 点击屏幕中央 60% 区域切换顶栏可见性 |
| 首页快捷按钮 | 顶部栏房子图标直接返回首页 |
| 图片预缓存 | 进入时预加载所有图片到本地 cache，翻页时预加载相邻页 |

#### 3.3.2 阅读进度记忆机制

```
打开漫画
  → LaunchedEffect(images): 查询 savedProgress
  → 有记录 → 弹出对话框
    → 点击"继续" → currentPageIndex = savedPage
    → 点击"从头开始" → currentPageIndex = 0
    → 关闭对话框 → currentPageIndex = 0
  → 无记录 → isProgressRestored = true，直接开始

翻页
  → LaunchedEffect(currentPageIndex, isImagesReady, isProgressRestored)
  → 条件满足 → viewModel.saveReadingProgress()

离开阅读器
  → DisposableEffect.onDispose → clearProgressDialogState()
```

**关键防护**：
- `isProgressRestored` 防止在进度恢复前误保存 page 0
- `handledProgressSessions`（ViewModel Set）防止对话框重复弹出
- `savedProgress = null` 在对话框处理后清除，防止状态残留
- `initialPageIndex` 从 ViewModel 同步初始化，防止 composable 重建时第一帧渲染 page 0

#### 3.3.3 水平翻页模式（HorizontalReader）

| 功能点 | 说明 |
|--------|------|
| HorizontalPager | 支持左右滑动翻页，`beyondBoundsPageCount = 1` 预加载相邻页 |
| 页码指示器 | 顶部显示"当前页 / 总页数" |
| 双击缩放 | 双击放大 2x，再双击还原 |
| 双指缩放 | `detectTransformGestures` 支持 pinch-to-zoom（1x~5x）|
| 放大后平移 | 放大状态下手势拖动图片 |
| 右侧进度条 | 见 3.3.5 |

#### 3.3.4 垂直长条模式（VerticalReader）

| 功能点 | 说明 |
|--------|------|
| LazyColumn | 所有图片垂直拼接，宽度填满屏幕 |
| 滚动速度检测 | 每 50ms 采样计算速度，超过 2000 单位/秒判定为快速滚动 |
| 右侧进度条 | 快速滚动时显示，见 3.3.5 |

#### 3.3.5 右侧胶囊进度条（SideProgressBar）

| 功能点 | 说明 |
|--------|------|
| 自动显示/隐藏 | 滚动时显示（50% 透明度），停止 3 秒后隐藏 |
| 点击显示 | 点击进度条区域时 100% 透明度显示 |
| 拖动跳转 | 按住拖动小球快速跳转到任意页，拖动时显示"页码/总页数"浮层 |
| 小球样式 | 14dp × 64dp 胶囊形，白色填充，黑色边框，阴影 8dp |
| 边界保护 | 小球始终完整显示在进度条范围内 |

**数据模型** `WebDavServerConfig`：
```kotlin
data class WebDavServerConfig(
    val id: String,        // UUID
    val name: String,      // 显示名称
    val url: String,       // 服务器地址（需含 http/https scheme）
    val username: String,
    val password: String,
    val lastPath: String?  // 上次浏览的目录路径（路径持久化）
)
```

## 四、数据模型

### Comic
```kotlin
data class Comic(
    val id: String,       // ZIP 文件名（不含扩展名）
    val title: String,    // 漫画标题（= 文件名）
    val filePath: String, // ZIP 文件完整路径
    val fileSize: Long    // 文件大小（字节）
)
```

### Chapter
```kotlin
data class Chapter(
    val number: String,      // 章节号（= 漫画本身，单话制）
    val images: List<String> // ZIP 内图片文件路径列表
)
```

### WebDavEntry
```kotlin
data class WebDavEntry(
    val name: String,        // 文件/文件夹名
    val path: String,        // 完整路径
    val isDirectory: Boolean,
    val size: Long           // 文件大小（目录为 0）
)
```

## 六、已知设计约束与注意事项

### 6.1 Compose 状态管理
- `remember(key)` 状态在 key 变化时重置，必须正确绑定 `comicId` / `chapter`
- ViewModel 中的 `handledProgressSessions` 在导航中持久存在，需手动清理
- `rememberPagerState.initialPage` 仅首次创建时生效，动态跳转需用 `LaunchedEffect + scrollToPage()`

### 6.2 阅读进度状态机
- `isProgressRestored` 必须为 `true` 后才允许保存进度，防止 page 0 覆盖真实进度
- `savedProgress` 在对话框处理后必须置 `null`，防止跨漫画切换时状态残留
- `DisposableEffect.onDispose` 清理 ViewModel 对话框状态

### 6.3 WebDAV
- URL 必须包含 `http://` 或 `https://` scheme（OkHttp 要求）
- `lastPath` 持久化确保用户每次打开从上次目录开始
- 首页快捷返回保护 `lastPath` 不被逐级返回时覆盖

### 6.4 单话漫画
- `chapters.size == 1` 时自动跳过章节列表
- 必须用 `hasAutoOpened` 防止返回后重复触发
